# Diplom
Черновое название Диплома (не по ГОСТ): Сниффер и декодер бинарного сетевого протокола СУБД
Черновое название НИР (не по ГОСТ): Сетевые угрозы безопасности СУБД и автоматная модель протокола обмена
НИР включает модель обнаружения аномальных выгрузок данных на основе статистических профилей (Базовый DLP), сравнительное экспериментальное исследование методов захвата сетевого трафика на высоких скоростях (High-Load Network Ingestion) и формализацию графа состояний бинарного протокола PostgreSQL (FSM).
Порт PostgreSQL: 5432.
