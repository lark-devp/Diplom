# Diplom

Рабочее название дипломной работы: **«Сниффер и декодер бинарного сетевого протокола СУБД»**.

## Научно-исследовательская работа

Рабочее название НИР: **«Сетевые угрозы безопасности СУБД и автоматная модель протокола обмена»**.

НИР включает разработку модели обнаружения аномальных выгрузок данных на основе статистических профилей — базового варианта DLP-системы. Кроме того, планируется сравнительное экспериментальное исследование методов захвата сетевого трафика на высоких скоростях (*High-Load Network Ingestion*).

Отдельное направление исследования посвящено формализации графа состояний бинарного протокола PostgreSQL на основе конечного автомата (*Finite State Machine*, FSM).

В качестве исследуемой СУБД используется PostgreSQL. Стандартный сетевой порт PostgreSQL — `5432`.
